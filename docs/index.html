CTR Prediction Using Machine Learning on Large-Scale Search Performance Data

Author

Inshrah Malik

Abstract

This research investigates the prediction of Click-Through Rate (CTR) using machine learning on the FlyRank ML Internship dataset. Search performance and engagement features such as impressions, average position, pageviews, sessions, and scroll events were used to train regression models. Linear Regression and Random Forest were evaluated using Mean Absolute Error (MAE), Mean Squared Error (MSE), and R². Experimental results demonstrate the effectiveness of machine learning for CTR prediction while highlighting the importance of feature engineering. This work provides a reproducible workflow for analysing large-scale search performance data.

Introduction

Click-Through Rate (CTR) is an important metric for measuring search performance and user engagement. Accurate prediction of CTR can help identify opportunities to improve content visibility and optimise search engine performance. This project was completed as part of the FlyRank Machine Learning Internship using production-scale search performance data.
